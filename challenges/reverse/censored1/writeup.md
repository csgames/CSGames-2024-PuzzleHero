# Censored 1

## Write-up

The first flag is censored with:

```python
def censor1(flag):
    out = ""
    for c in flag:
        if c.isalpha():
            rand = 0
            while not rand:
                rand = int(random() * 26)
            start = ord('A') + (ord(c) & 32)
            num = ord(c)
            num -= start
            num += rand
            num %= 26
            num += start
            out += chr(num)
        else:
            out += c
    return out
```

Each flag is rotated by a random amount between 1 and 25
included. Thus, no letter is ever rotated to itself.
