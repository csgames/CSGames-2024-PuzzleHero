# Gimme the tea

## Write-up

The first thing the scientist says hints to give an URL. You had to give him an URL that returned [HTTP status code 418 "I'm a teapot"](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/418). You could use any URL that returned the code, but https://google.com/teapot was one of them. The scientist then gave you the flag.
