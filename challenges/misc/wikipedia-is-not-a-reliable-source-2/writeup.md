# Wikipedia is not a reliable source II

## Write-up

There used to be a flag in a section that talked about the Puzzle Hero competition on the CS Games Wikipedia page, but it was not in the right flag format. As the `=` character hinted, the string inside the flag was a base64-encoded string, `FLAG_dooonateTothewikimediaFoundation`. 

However, quite ironically, since the modification was not correctly sourced, it was removed by another contributor, `Hoolen`, less than 6 hours later. Hence, it can be found in the history, under the modification entitled `Ajout d'une explication de ce qu'est le Puzzle Hero`
